# Видео 10–20 секунд

Запишите экран через OBS, Xbox Game Bar, macOS Screenshot или другой рекордер.

1. 0–4 с: показать дашборд с демо-данными.
2. 4–9 с: добавить операцию.
3. 9–14 с: показать обновлённые KPI и графики.
4. 14–18 с: применить фильтр по категории.

Сохранить как `docs/demo.mp4`, проверить воспроизведение и добавить в GitHub.
