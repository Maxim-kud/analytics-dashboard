# Ошибки и исправления

## 1. Ошибка запуска PostgreSQL
Порт 5432 оказался недоступен в Windows.

Решение: изменён порт на 5433 в docker-compose.yml и файле .env.

Результат: PostgreSQL успешно запущен, статус контейнера Healthy.

## 2. Ошибка установки зависимостей
Файл requirements.txt не находился из-за вложенной папки проекта.

Решение: переход в правильную директорию проекта.

## 3. Ошибка запуска тестов
ModuleNotFoundError: No module named 'src'.

Решение: запуск pytest из корневой директории приложения.

Результат: 6 passed in 0.47s.
